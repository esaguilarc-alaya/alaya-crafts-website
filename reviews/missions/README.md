# Website missions

This is the durable exchange point for issued Alaya Website missions. Read
[`docs/engineering-control/README.md`](../../docs/engineering-control/README.md)
before issuing, executing, or reviewing work.

Create `reviews/missions/<MISSION-ID>/` only at issuance. The committed
`mission.md` is immutable. The implementation actor writes its return beside
it; Codex writes a separate disposition. Do not execute a mission by filename
order or inferred status—use only the exact ID, path, and issuance commit
dispatched by Codex.
