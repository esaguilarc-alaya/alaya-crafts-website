I kept `.feature-title` as a rescale-only modifier class on `<h2>` where a real semantic distinction existed (the featured item's title is visually the largest element on the index page) but did not import the study's generic `.display`/`.headline` utility-class system, matching the `.organizations-page`/`.cie-page` h1/h2/h3-scoped convention already established for the two most recently accepted pages, over the older `home.mjs`/`cie.mjs` bootstrap era's own now-superseded utility classes.
