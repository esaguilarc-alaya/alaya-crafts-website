# Working in this repository

Every disposable implementation or review session starts at
[`docs/engineering-control/README.md`](docs/engineering-control/README.md).
Read the assigned actor contract and the exact dispatched mission packet before
mission work. Repository artifacts—not chat history—define authority.

Do not select a mission by recency. Execute only the exact mission ID, path, and
issuance commit dispatched by the Codex control owner. Stop on a state mismatch
or an incomplete packet. Preserve unrelated working-tree changes.
